Privacy Policy

Last updated: October 25, 2026

Dalal Family Agents are private AI assistants used only by members of one family. They are not a public product.

What Google data is accessed

With the account owner's permission, the assistant reads Gmail messages using read-only access (gmail.readonly). It cannot send, delete, or change email.

How it is used

Email content is used only to provide features to the account owner who granted access, such as summarizing messages and helping plan schoolwork. It is not sold, shared, or used for advertising, and it is not used to train AI models beyond processing by the AI model provider needed to answer the account owner's requests.

Storage and security

Access credentials are stored on a private server with restricted permissions. Email content is processed on demand and is not copied into any separate database.

Revoking access

The account owner can revoke access at any time in their Google Account under Security → Third-party connections.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
